## The network (what is connected to what)
```
Phone hotspot ── Wi-Fi ── DELL G3 (portal) ── Ethernet 192.168.1.200 (no gateway) ── Smart Lab router 192.168.1.1
                                                                                      ├─ FANUC .100, UR5e .102 (robots, static)
                                                                                      ├─ cameras .155 / .156, ESP32s .150-.152
                                                                                      └─ LAB ENGINEER PC  USB-Ethernet 192.168.1.210 (no gateway)
                                                                                                         + GIU LAN 10.40.20.x (its normal network)
GIU LAN 10.40.20.x ── PC-01 .. PC-16  (untouched; they reach the portal THROUGH the engineer PC relay)
```
Key fact: the GIU PCs have **no route** to 192.168.1.200. At home it worked because both PCs were on one router.
`tools/relay/relay.py` on the engineer PC forwards GIU -> portal (ports 8000, 443, 80). Tested 2026-11-03: API 200
and HTTPS 200 through the relay; 3 unit tests pass on Python 3.12 and 3.14.
